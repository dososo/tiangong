## 三、几个造型决定

1. **天宫悬在一架浑天仪的轴心。** 浑天仪是古人量天的仪器。画里把量天的仪器放大成天本身，环就是天道，宫在环心，日月沿环走。
2. **三十三重天，抬头看是藻井，低头看是曼荼罗。** 两样东西结构相近：都是一圈套一圈的方与圆。镜头只翻一次身，观众自己会发现。
3. **结尾收进一只眼睛。** 全片最大的东西装进最小的东西里，典出《维摩诘经》。随后一眨眼，他又只是画里一个点。「震撼」不在大，在大小忽然对调的那一下。
4. **日中有乌，月中有兔。** 金乌与玉兔是第四回原文就有的意象；形象按《论衡》《淮南子》的说法取「三足乌」「月中兔」。
5. **配乐以钟开、以磬收。** 典出《孟子》「金声玉振」。音阶用宫调式，四度升高（D 宫，F♯、G♯、A、B、C♯），取雅乐的「变徵」。
6. **没有人脸特写，没有台词。** 玉帝始终没有现身，只有光。
